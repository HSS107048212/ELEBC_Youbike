# ELEBC_Youbike
## 🚴‍♂️ YouBike Earned Value Tracker
This repository fetches **YouBike public bike sharing data** from the [Taipei City Government Open Data Platform](https://data.taipei/) and applies **Earned Value Management (EVM)** to evaluate the operational effectiveness of each station.
### 🔍 Earned Value Concepts

| Metric | Description |
|--------|-------------|
| **EV** (Earned Value) | Value of actual work completed (e.g., based on real-time usage or defined targets) |
| **PV** (Planned Value) | Value of planned work (e.g., expected availability/utilization) |
| **AC** (Actual Cost) | Actual resources or efforts spent (can be proxied with maintenance frequency, etc.) |

From these, you can compute:
- **SPI** = EV / PV (Schedule Performance)
- **CPI** = EV / AC (Cost Efficiency)
